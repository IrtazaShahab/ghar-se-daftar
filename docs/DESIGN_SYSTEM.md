# Ghar Se Daftar Design System

## Brand Positioning

**Ghar Ka Khana, Ab Daftar Tak.**

Premium homemade meal subscription platform. Not fast food. Not a restaurant marketplace.

## Brand Attributes

- Premium
- Homemade
- Pakistani
- Trustworthy
- Women-led
- Healthy alternative to fast food
- Corporate-friendly

## Components

- Rounded premium cards
- Warm cream glass surfaces
- Green primary buttons
- Pill-shaped CTAs
- Soft hover lift
- Minimal Framer Motion reveals
- Sticky WhatsApp CTA on mobile

## UX Rules

1. Always explain this is homemade, not restaurant/fast food.
2. Show weekly menu before deep signup.
3. Use two meal options per day.
4. Keep WhatsApp as fallback conversion channel.
5. Make corporate ordering separate from individual subscriptions.
6. Add trust near every CTA.
7. Never expose personal chef addresses publicly.
